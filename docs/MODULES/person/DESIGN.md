# 人员模块设计

> **版本**：v1.0
> **服务**：PersonService (5018)
> **状态**：规划中

---

## 1. 概述

人员模块是 WO 物业管理软件的公共服务模块，负责统一管理所有人员信息。

### 1.1 核心职责

```
PersonService (5018) 职责：
  - 人员 CRUD
  - 部门枚举管理
  - 职位枚举管理
  - 人员类型管理（员工/住户/业主/访客）
```

### 1.2 服务特点

```
✓ 公共服务：
  - 不调用任何业务服务
  - 只被业务服务调用

✓ 共享数据：
  - 所有业务表都引用 PersonId
  - 人员信息统一管理
```

---

## 2. API 列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/persons | 获取人员列表 |
| GET | /api/persons/{id} | 获取人员详情 |
| POST | /api/persons | 创建人员 |
| PUT | /api/persons/{id} | 更新人员 |
| DELETE | /api/persons/{id} | 删除人员 |
| GET | /api/enums/{type} | 获取枚举值 |
