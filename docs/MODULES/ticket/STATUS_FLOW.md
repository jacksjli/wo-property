# 工单状态流转

> **版本**：v1.0
> **模块**：ticket
> **最后更新**：2026-05-05

---

## 1. 状态定义

| 状态值 | 名称 | 说明 |
|--------|------|------|
| Created | 已创建 | 工单创建，待派单 |
| Dispatched | 已派单 | 已分配给处理人，待接单 |
| Accepted | 已接单 | 处理人已接单，处理中 |
| Rejected | 已拒单 | 处理人拒绝，需重新派单 |
| InProgress | 处理中 | 处理人正在处理 |
| Finished | 已完工 | 处理人申请完工，待确认 |
| Confirmed | 已确认 | 业主/管理员确认完工 |
| Closed | 已关闭 | 工单结束 |

## 3. 状态流转 API

| 方法 | 路径 | 触发者 | 说明 |
|------|------|--------|------|
| POST | /api/tickets | 用户 | 创建工单，状态=Created |
| POST | /api/tickets/{id}/dispatch | TicketService→DispatchService | 派单请求，状态→Dispatched |
| POST | /api/tickets/{id}/accept | 处理人 | 接单，状态→Accepted |
| POST | /api/tickets/{id}/reject | 处理人 | 拒单，状态→Rejected |
| PUT | /api/tickets/{id}/progress | 处理人 | 更新进度，状态→InProgress |
| POST | /api/tickets/{id}/finish | 处理人 | 完工申请，状态→Finished |
| POST | /api/tickets/{id}/confirm | 业主/管理员 | 确认完工，状态→Confirmed |
| POST | /api/tickets/{id}/rate | 业主 | 评价(1-5星)，状态→Closed |

## 4. 状态说明

### 4.1 Created（已创建）

**进入条件**：
- 用户提交新工单

**允许操作**：
- dispatch：派单

**离开条件**：
- 派单成功 → Dispatched
- 超时未派单 → （待定）

### 4.2 Dispatched（已派单）

**进入条件**：
- TicketService 调用 DispatchService 完成派单

**允许操作**：
- accept：接单
- reject：拒单
- timeout：派单超时，返回 Created

**离开条件**：
- 处理人接单 → Accepted
- 处理人拒单 → Rejected
- 派单超时 → Created（重新派单）

### 4.3 Accepted（已接单）

**进入条件**：
- 处理人接受工单

**允许操作**：
- progress：更新进度

**离开条件**：
- 处理人更新进度 → InProgress

### 4.4 Rejected（已拒单）

**进入条件**：
- 处理人拒绝工单

**离开条件**：
- 自动返回 Created，等待重新派单

### 4.5 InProgress（处理中）

**进入条件**：
- 处理人开始处理工单

**允许操作**：
- finish：完工申请

**离开条件**：
- 处理人申请完工 → Finished

### 4.6 Finished（已完工）

**进入条件**：
- 处理人申请完工

**允许操作**：
- confirm：确认完工
- 返回 InProgress：需返工（较少见）

**离开条件**：
- 业主/管理员确认 → Confirmed

### 4.7 Confirmed（已确认）

**进入条件**：
- 业主/管理员确认完工

**允许操作**：
- rate：评价

**离开条件**：
- 业主评价 → Closed

### 4.8 Closed（已关闭）

**最终状态**，不可流转。
