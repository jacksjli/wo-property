# 新电脑环境准备指南

## 概述

在运行部署脚本之前，新电脑需要安装以下软件。本指南提供各软件的推荐版本和安装方法。

---

## 一、安装清单

| 软件 | 推荐版本 | 必须 | 用途 |
|------|----------|------|------|
| Git | 2.40+ | ✅ | 代码管理 |
| Docker | 24.0+ | ✅ | 容器化部署 |
| Node.js | 20.x LTS | ✅ | 编译小程序 |
| 微信开发者工具 | 最新版 | ✅ | 小程序调试 |

---

## 二、安装详细说明

### 2.1 Git 安装

#### macOS

**方法一：Homebrew（推荐）**

```bash
# 如果没有 Homebrew，先安装
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 Git
brew install git

# 验证版本
git --version
# 输出示例：git version 2.40.1
```

**方法二：直接下载**

访问：https://git-scm.com/download/mac

下载 `.pkg` 文件，双击安装。

---

#### Windows

**方法一：Chocolatey（推荐）**

```powershell
# 安装 Chocolatey（如果未安装）
powershell -Command "Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))"

# 安装 Git
choco install git -y

# 验证版本
git --version
```

**方法二：直接下载**

访问：https://git-scm.com/download/win

下载 64-bit Git for Windows Setup。

---

#### Ubuntu / Debian

```bash
sudo apt-get update
sudo apt-get install git

# 验证版本
git --version
```

---

### 2.2 Docker 安装

#### macOS

**方法一：Homebrew（推荐）**

```bash
brew install --cask docker

# 启动 Docker Desktop
open -a Docker

# 验证版本
docker --version
```

**方法二：直接下载**

访问：https://www.docker.com/products/docker-desktop/

下载 Docker Desktop for Mac。

> ⚠️ 安装完成后需要启动 Docker Desktop 应用

---

#### Windows

**要求**：Windows 10/11 专业版或企业版（支持 WSL2）

**方法：直接下载**

访问：https://www.docker.com/products/docker-desktop/

下载 Docker Desktop for Windows。

> ⚠️ 需要启用 WSL2 功能，安装后需要重启电脑

---

#### Ubuntu / Debian

```bash
# 安装 Docker
curl -fsSL https://get.docker.com | sh

# 验证版本
docker --version
```

---

### 2.3 Node.js 安装

#### macOS

**方法一：Homebrew（推荐）**

```bash
brew install node@20

# 验证版本
node --version
npm --version
```

---

#### Windows

**方法：直接下载（推荐）**

访问：https://nodejs.org/

下载 LTS 版本（20.x）。

---

#### Ubuntu / Debian

```bash
# 使用 NodeSource 仓库
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -

sudo apt-get install -y nodejs

# 验证版本
node --version
npm --version
```

---

### 2.4 微信开发者工具

#### macOS / Windows

1. 访问：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 下载对应版本
3. 双击安装

## 三、验证安装

### 检查清单

安装完成后，在终端运行以下命令验证：

```bash
# 1. 验证 Git
git --version
# 预期：git version 2.40.x 或更高

# 2. 验证 Docker
docker --version
# 预期：Docker version 24.x.x 或更高

# 3. 验证 Docker 运行状态
docker info
# 预期：显示 Docker 引擎信息

# 4. 验证 Node.js
node --version
# 预期：v20.x.x

# 5. 验证 npm
npm --version
# 预期：10.x.x
```

## 四、部署步骤

### Step 1: 拷贝部署包

将 `deploy-ticket` 文件夹拷贝到桌面。

### Step 2: 运行部署脚本

```bash
# macOS / Linux
cd ~/Desktop/deploy-ticket
bash scripts/deploy.sh

# Windows (PowerShell)
cd $HOME\Desktop\deploy-ticket
.\scripts\deploy.bat
```

**等待时间**：首次部署需要 5-10 分钟（编译所有服务）

### Step 3: 验证服务

```bash
# macOS / Linux
bash scripts/verify.sh

# Windows
.\scripts\verify.bat
```

### Step 4: 删除源代码（可选）

编译完成后，可以删除源代码以释放空间：

```bash
# macOS / Linux
cd ~/Desktop/deploy-ticket
rm -rf src/
rm -rf woa-property-mini/
rm -rf dockerfiles/

# Windows (PowerShell)
cd $HOME\Desktop\deploy-ticket
Remove-Item -Recurse -Force src\
Remove-Item -Recurse -Force woa-property-mini\
Remove-Item -Recurse -Force dockerfiles\
```

**删除后保留的文件**：

```
deploy-ticket/
├── docker-compose.yml   ← 启动服务必须
├── .env                 ← 环境配置
├── init.sql             ← 数据库初始化
├── scripts/             ← 运维脚本
└── installers/          ← 安装包
```

### Step 5: 编译小程序

如果删除了小程序源码，需要重新编译：

```bash
cd ~/Desktop/deploy-ticket/woa-property-mini
npm install
npm run build:mp-weixin
```

## 六、常见问题

### 6.1 Docker 启动失败 (macOS)

```bash
# 重启 Docker Desktop
killall Docker
open -a Docker
```

### 6.2 权限问题 (Linux)

```bash
# 将当前用户添加到 docker 用户组
sudo usermod -aG docker $USER

# 重新登录使生效
exit
```

### 6.3 Node.js 版本不对

```bash
# 使用 nvm 切换版本
nvm install 20
nvm use 20
```

### 6.4 删除源码后需要重新部署怎么办？

**建议**：在删除源码前创建备份

```bash
# 部署成功后，创建备份
cp -r deploy-ticket deploy-ticket-backup
```

如果删除了源码，需要重新拷贝整个 `deploy-ticket` 文件夹。
