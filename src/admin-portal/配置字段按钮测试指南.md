# 配置字段按钮测试指南

## 测试步骤

### 1. 登录系统
- 访问: http://localhost:5173/
- 用户名: admin
- 密码: Admin@123

### 2. 进入项目
- 选择任意项目（如：物业设备管理）
- 点击「进入」按钮

### 3. 测试各模块的配置字段按钮

#### 住户管理模块
1. 点击左侧菜单「住户管理」
2. 查看页面右上角是否有「配置字段」按钮
3. 点击「配置字段」按钮
4. 输入管理员密码: Admin@123
5. 检查是否弹出字段配置对话框
6. 尝试拖拽字段重新排序
7. 尝试启用/禁用字段
8. 点击「保存配置」

#### 人员管理模块
1. 点击左侧菜单「人员管理」
2. 查看页面右上角是否有「配置字段」按钮
3. 点击「配置字段」按钮
4. 输入管理员密码: Admin@123
5. 检查是否弹出字段配置对话框
6. 查看字段列表是否包含：姓名、电话、角色、专长、状态、备份人员
7. 尝试修改字段配置

#### 其他模块测试（抽样）
- 工单管理
- 缴费管理
- 设备管理
- 合同管理

## 预期结果

✅ 所有模块都有「配置字段」按钮
✅ 点击按钮需要管理员密码验证
✅ 密码正确后显示字段配置对话框
✅ 可以拖拽字段重新排序
✅ 可以启用/禁用字段
✅ 保存配置后刷新页面，配置应保持不变

## 测试账号

- 管理员: admin / Admin@123
- 技术员: tech / Tech@123
- 普通用户: user / User@123

## 注意事项

1. 只有管理员可以修改字段配置
2. 普通用户可以看到「配置字段」按钮，但点击后需要输入管理员密码
3. 字段配置保存在 localStorage 中
4. 不同项目之间的字段配置是独立的
